## 🛠️ How to Run the Code

To run any of the examples or exercises locally, make sure you have Go installed on your machine.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/lukinhapdm/go-learning.git
   ```

2. **Navigate to the specific exercise directory (example):**
   ```bash
   cd basics/pt1
   ```

3. **Run the Go file:**
   ```bash
   go run file-name-here.go
   ```
